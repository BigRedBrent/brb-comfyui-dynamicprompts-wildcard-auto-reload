# Dynamic Prompts Wildcard Auto Reload

A ComfyUI add-on for [comfyui-dynamicprompts](https://github.com/adieyal/comfyui-dynamicprompts) that reloads wildcard files automatically when they're added, removed or changed, so edits are used on the next run without restarting ComfyUI. It also allows spaces between a weight and "::", like `{3  ::red|blue}`, so weights can be lined up.
